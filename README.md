# Spam Email Detection Using Machine Learning

## Project Overview
This project detects whether an email or text message is Spam or Not Spam using Natural Language Processing (NLP) and Machine Learning techniques.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- NLTK
- Scikit-learn
- TensorFlow/Keras

## Project Workflow
1. Import the dataset.
2. Perform data cleaning and preprocessing.
3. Remove stopwords and unnecessary characters.
4. Convert text into numerical representations.
5. Train the machine learning model.
6. Predict whether an email is Spam or Not Spam.
7. Evaluate model performance.

## Features
- Email text preprocessing
- Spam and Ham classification
- Machine learning-based prediction
- Model evaluation

## How to Run
1. Download the notebook.
2. Open it using Google Colab.
3. Upload the required dataset.
4. Run all cells to train and test the model.
